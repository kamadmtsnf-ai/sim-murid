# Kewajiban penggunaan PWA — 28 Oktober 2026

Instruksi pengguna: tombol pemasangan harus berada **di dalam footer**, PWA diperbarui, dan pengguna selain admin diwajibkan menggunakannya melalui PWA.

- Semua akun non-admin melewati layar persiapan sebelum antarmuka layanan account dapat digunakan. Hanya identitas `is_admin` yang diverifikasi server memberi pengecualian; label, username, capability menyerupai admin atau localStorage tidak memberi pengecualian.
- Pengguna tetap harus menyetujui pemasangan melalui browser/OS. Prompt diterima atau event `appinstalled` bukan bukti aplikasi telah dibuka standalone. Harus membuka ikon aplikasi, lalu login bila perlu.
- Mode yang diperiksa: `display-mode: standalone`, atau `navigator.standalone` pada iOS. Fullscreen browser tidak dianggap PWA. Tanpa dukungan pemasangan, non-admin diminta memakai browser/perangkat yang mendukung atau menghubungi admin; tidak ada tombol lewati kebijakan.
- Ini **kebijakan penggunaan antarmuka**, bukan attestation OS, bukan mekanisme autentikasi atau batas keamanan baru. Sinyal browser dapat dimanipulasi; server tidak dapat membuktikan instalasi PWA dari sinyal ini. API/RBAC/RPC/RLS tetap sumber otorisasi; tidak menambah header/cookie “sudah instal” yang dipercaya untuk akses.
- Tidak menyimpan kredensial atau data privat untuk offline. Tidak mendaftarkan service worker, mengantrekan transaksi offline, memuat ulang otomatis, memindahkan sesi via URL atau menandai instalasi di database.
- Login/pemulihan publik tetap tersedia di browser agar admin dapat masuk dan pengguna dapat menyiapkan akses. Sesi non-admin yang valid tetap wajib standalone di area account, termasuk keamanan/email/survei. Logout dengan konfirmasi tetap tersedia pada layar wajib.
- D01/D02/D03/D10 dan seluruh kebijakan akademik/keuangan tidak berubah.

Acuan platform: [MDN beforeinstallprompt](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeinstallprompt_event), [MDN standalone](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Create_a_standalone_app). `beforeinstallprompt` tidak tersedia di semua browser; panduan manual tetap diperlukan.
